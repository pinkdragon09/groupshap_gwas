# Historical analysis scripts

This directory preserves exploratory analysis code that informed the project but
is not executed by the main reproduction paths. It includes the
pre-PyALE Phase 5 implementation, earlier fixed-panel Study 27 comparisons,
Transformer experiments, alternative FT10 and Study 43 model runs, simulation
checks, yeast interaction/ablation experiments, and their verification helpers.

These scripts can depend on old output locations, larger genotype matrices, or
superseded methods. They are kept for provenance and exploration, not as
current methods or report evidence. Current runs use the top-level `scripts/`
entry points, `xai_gwas/`, and the pinned PyALE implementation.
