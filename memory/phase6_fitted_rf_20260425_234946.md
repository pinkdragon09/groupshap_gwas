# Fitted-RF simulation protocol

**Note date:** 2026-04-25 23:49:46

The fitted-model simulation used the RF settings below, matching the LD-confounding
simulation in `scripts/history/run_benchmark.py`:

```python
RandomForestRegressor(n_estimators=100, random_state=seed, n_jobs=-1)
# Regression defaults used: max_features=1.0, min_samples_leaf=1.
```

`scripts/run_phase6_fitted_rf.py` used an 80/20 train/test split with
`random_state=seed`. RF fitting used the training slice. Group attribution and
interaction evaluation used the held-out slice, with 100 background rows and
20 evaluation rows sampled from that slice.

The linear-GWAS signal-to-noise comparator used the full 2,000-sample dataset.
That sampling difference matters when interpreting the comparison: the RF
explanations used a fitted model and held-out rows, whereas the linear comparator
was not restricted to the same evaluation slice.
