# Bloom yeast data acquisition and loader checks

**Note date:** 2026-04-25 17:29:27

The acquisition combined the Bloom 2013 BY×RM genotype/phenotype tables with the
Bloom 2015 supplementary QTL-interaction table. The 2013 genotype matrix contained
1,008 segregants and 11,623 markers; the phenotype table contained 46 traits.
The 2015 interaction table contained 205 published pairs across 19 traits.

The loader is `scripts/load_yeast_bloom.py`. The retained interaction table is
`data/yeast-byxrm/processed/Bloom2015_SuppData4_QTLxQTL_interactions.csv`.
Downloaded files were checked using SHA256, size and retrieval metadata.
The supplementary XLS tables were converted to CSV with headless LibreOffice
because the session's Python environment lacked the spreadsheet-reading packages.

A Raffinose smoke test retained 662 segregants after dropping missing phenotypes.
It used a 200-tree random forest, five-fold CV and seed 42. The recorded fold R²
values were 0.316, 0.339, 0.419, 0.276 and 0.318; runtime was 67 seconds.
The interaction table listed 11 Raffinose pairs for potential subsequent comparison.
This was a data-loading and fitting check, not an interaction-recovery experiment.

Two acquisition steps remained deferred: PLINK conversion, because PLINK was
unavailable in that session, and loading the expanded 2015 RData matrix of
4,390 segregants by 28,880 markers, because `pyreadr` was unavailable. The Python
loader could use the 2013 text tables without PLINK. These dependency statements
describe the historical session, not the current environment.

Trait matching needs chemical-name checks. The 2013 phenotype `Magnesium_Sulfate`
and the 2015 phenotype `ManganeseSulfate` are different compounds. Removing
punctuation or normalizing case must not merge them. The 25 ManganeseSulfate pairs
cannot be evaluated with a 2013 phenotype that measures magnesium sulfate.
The acquisition record does not imply that every downloaded raw file is bundled
with the current archive.
