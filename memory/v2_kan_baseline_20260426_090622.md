# Bloom yeast KAN baseline configuration

**Note date:** 2026-04-26 09:06:22

The yeast Neomycin/Lactate baseline used pykan 0.2.8 and
`KAN(width=[p_panel, 8, 1], grid=5, k=3, seed=42)`. Here `p_panel` is the number
of SNP predictors in the phenotype's feature panel. The model has eight hidden
units, one output, a five-interval B-spline grid and cubic splines.

Training used Adam with learning rate 0.001, batch size 64, at most 200 epochs,
and early stopping after 25 epochs without validation-MSE improvement.
The executed 200/25 epoch/patience settings differed from a proposed 500/50
configuration; the executed values are the ones recorded here.

The retained training implementation is `scripts/history/yeast_bloom_kan_train.py`.
