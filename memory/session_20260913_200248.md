# AraPheno Study 43 five-fold pilot

**Note date:** 2026-09-13 20:02:48

The pilot evaluated carbon isotope discrimination, stomatal density and stomatal
size in 310 complete-case accessions. It fitted separate RF models, a joint RF,
and three single-output KANs across five outer folds, using one seed per fold.

`scripts/fivefold_common.py` supplied ID-based splits, split validation,
fitted scaling, exact grouped coalition games, checksums and resumable completion
receipts. `scripts/run_study43_fivefold.py` selected features separately for
inner and outer training panels. KAN epoch selection used only inner validation,
followed by a fresh fit on the outer training rows.

All 310 accessions received held-out explanations once per model family, using
20 training-background rows per fold. Chromosome attributions and interactions
were saved with predictions. The retained numerical results are under
`outputs/arapheno_study43/`.

All five folds finished. Seven analytic/integrity checks passed. Resume testing
verified and skipped a completed fold. The checkpoint verifier reloaded all
15 fold/model families and reproduced predictions with zero maximum error;
it also checked target scalers and training-marker variances. Additional checks
covered complete out-of-fold coverage, background identities, Shapley efficiency
and signed joint linearity.

Recorded mean fold R² values were:

| Model | Carbon isotope | Stomatal density | Stomatal size |
|---|---:|---:|---:|
| Separate RF | 0.0975 | 0.0127 | -0.0027 |
| Joint RF | 0.1072 | 0.0106 | 0.0008 |
| KAN | 0.0408 | -0.0356 | -0.2314 |

This record describes a one-seed-per-fold pilot. It does not establish significant
model superiority or biological causation. Repeating checkpoint verification
requires the fitted model files or a fresh model-training run.
