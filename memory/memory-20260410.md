# Simulation benchmark runtime changes

**Note date:** 2026-04-10

The simulation runner `scripts/history/run_benchmark.py` was changed after a run
stalled. The number of linkage-disequilibrium blocks was reduced from 50 to 10,
the SNP count from 1,000 to 200, and the replicate count from 200 to 100.
Parallel execution changed from threads to processes, and progress messages were added.

These changes reduced the workload and made execution progress observable.
This record does not report a measured speedup or establish that the smaller
benchmark has the same statistical precision as the larger design.
