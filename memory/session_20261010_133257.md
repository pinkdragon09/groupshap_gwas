# Shared ALE implementation and PyALE reference checks

**Note date:** 2026-10-10 13:32:57

The ALE migration pinned PyALE 1.2.0, consolidated first-order ALE into
`xai_gwas/attribution/ale.py`, and added a binary specialization for the five-fold
workflows. Discrete adjacent-state contrasts pool observations from both states
and use frequency-weighted centering. The binary specialization retains per-row
contrasts and is checked against discrete PyALE.

The implementation and reference fixtures cover binary and three-level SNPs,
including correlated interacting predictors. Script wrappers delegate to the
shared estimator instead of maintaining separate first-order implementations.
The legacy two-dimensional SNP routine remains separate and carries a warning.

Recorded validation included 25 reference/attribution/five-fold tests, a final
focused rerun of 19 tests, two analytical ALE checks and a clean whitespace check.
This session did not retrain models or replace historical outputs. Its validation
record applies to the ALE migration, not a claim of improved predictive accuracy.
