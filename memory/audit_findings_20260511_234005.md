# AraPheno metadata record-count audit

**Note date:** 2026-05-11 23:40:05

The AraPheno data description stated 537 phenotypes and 30 studies. A line-count
check instead returned 558 lines for the phenotype metadata CSV and 69 lines for
the study metadata CSV. Physical CSV lines are not necessarily data records:
quoted fields can contain embedded newlines, and the header also occupies a line.

The required follow-up was to count parsed records in
`data/arapheno/metadata/phenotype_list.csv` and
`data/arapheno/metadata/study_list.csv`, then reconcile the description.
This note records the discrepancy and the proposed check; it does not establish
corrected counts or claim that the check was completed.
