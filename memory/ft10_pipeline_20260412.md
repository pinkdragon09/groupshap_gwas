# FT10 RF and gene-window attribution pipeline

**Note date:** 2026-04-12

`scripts/history/run_ft10_nonlinear.py` implemented a random-forest workflow for
the FT10 flowering-time phenotype in AraPheno Study 1. It used Araport11 gene
annotations with 25 kb flanks to construct gene-window groups for grouped Shapley analysis.

The numerical output set included cross-validation metrics, per-SNP SHAP,
gene-window grouped Shapley values and permutation importance. Retained outputs
are under `outputs/history/ft10/ft10/`.

This note records the early pipeline and its output types, without making a
claim about predictive performance or recovery of biological loci.
