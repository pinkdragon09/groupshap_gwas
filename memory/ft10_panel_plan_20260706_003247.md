# FT10 canonical-locus feature-panel plan

**Note date:** 2026-07-06 00:32:47

The proposed AraPheno Study 1 FT10 analysis would include known flowering-time
loci before model fitting and attribution, alongside a GWAS-selected SNP
background and kinship-PC controls. This note specifies the design, not a completed run.

The intended loci were FLC (`AT5G10140`), FRI (`AT4G00650`), FT
(`AT1G65480`), VIN3 (`AT5G57380`) and DOG1 (`AT5G45830`). Gene identities,
coordinates and strand were to be checked against Araport11 annotation.

The panel would contain:

1. SNPs in each canonical gene body plus a 50 kb flank. If a window was empty,
   try 100 kb and record the change. Keep the contributing gene labels.
2. The top 200 PC-adjusted GWAS SNPs as a background set. Deduplicate by HDF5
   SNP index while preserving all feature-source labels.
3. Three kinship PCs as predictive covariates. Keep them separate from biological
   gene rankings, with optional covariate-importance summaries.

Align FT10 accessions with genotype and kinship identifiers, inspect the HDF5
metadata before extracting windows, and save a machine-readable panel manifest.
The intended runner is retained as `scripts/history/run_ft10_biocomplete.py`.

RF settings were 200 trees, `max_features="sqrt"`, `min_samples_leaf=2`,
`random_state=42 + fold` and `n_jobs=-1`. Use five shuffled folds with seed 42.
Compare the full canonical+GWAS+PC model against PCs only, GWAS SNPs+PCs, and
canonical SNPs+PCs using matched folds. This historical proposal precedes the
implementation's additional minor-allele-count filter.
