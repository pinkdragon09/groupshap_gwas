# Grouping, permutation importance and ALE helpers

**Note date:** 2026-04-09 17:24:21

The shared attribution workflow gained four grouping helpers:
`assign_snps_to_gene_windows`, `build_gene_window_groups`, `build_ld_block_groups`
and `build_cis_window_groups`. They support assigning SNPs to gene windows,
linkage-disequilibrium blocks and cis windows.

The additions also included `conditional_permutation_importance` and `ale_effect`.
These names identify implementation functions; the legacy permutation-function
name does not itself establish that a conditional genotype sampler was used.

The retained helper module is `scripts/grouped_shap_utils.py`. This record dates
the helper additions and does not describe later changes to the ALE estimator.
