# Small-sample CNN stability and deep-SHAP limits

**Note date:** 2026-04-01 09:47:04

`scripts/transformer_mamba_gwas_template.py` provided CNN, Transformer and Mamba
model options, plus a debug mode, for genotype-to-phenotype prediction.

The CNN path was patched for small samples by removing BatchNorm and the CNN-head
LayerNorm, standardizing inputs and targets within each fold, using SmoothL1Loss,
and clipping gradients.

Deep SHAP for the CNN and Transformer required `check_additivity=False` and emitted
unsupported-operation warnings for LayerNorm. Those explanations were treated as
exploratory. The Mamba path had not been executed because `mamba_ssm` was absent
from the environment used for that session.

These are historical model experiments; the package-availability statement applies
to that session, not necessarily to the current workstation.
