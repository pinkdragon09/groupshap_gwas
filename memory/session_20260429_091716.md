# AraPheno Study 43 multi-output KAN wrapper

**Note date:** 2026-04-29 09:17:16

`scripts/history/run_joint_kan_study43.py` trained three separate single-output
KANs for the three AraPheno Study 43 phenotypes and combined their predictions
through `JointKanWrapper`.

Each model used width `[100, 8, 1]`, a five-interval spline grid, cubic splines
and 200 Adam epochs. The wrapper returned an `(n_samples, 3)` prediction array
for the joint value function. It combined separately fitted KANs; it did not
train a single shared multi-output KAN.

The grouped Shapley calculation used two folds, 20 coalition samples,
20 background rows and 10 evaluation rows. These explicit settings identify
this early experiment separately from later five-fold workflows.
