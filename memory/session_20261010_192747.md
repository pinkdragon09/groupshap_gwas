# Yeast training-set and held-out GroupSHAP analysis

**Note date:** 2026-10-10 19:27:47

The extension explained all 20 saved seed-42 RF/KAN fold models for Neomycin and
Lactate without refitting: two phenotypes, two model families and five folds.
It added training-set explanations alongside the existing held-out explanations.

`scripts/yeast_grouped_explanations.py` implements the batch engine,
`scripts/run_yeast_training_groupshap.py` runs the extension, and
`scripts/history/verify_yeast_training_groupshap.py` verifies it. Numerical
comparisons and manifests are retained under `outputs/yeast_bloom_training_heldout/`.

Groups were whole chromosomes over each fold's selected SNP panel, not genes,
pathways or sums of separate SNP Shapley values. Main-effect summaries used all
rows. Interaction comparisons used matched 20-row training and held-out samples,
the same ten background donors and ten coalition samples. The interaction index
used the full convention without a one-half factor.

Nine engine checks and nine subset-contract checks passed. All 20 models passed
independent verification of checkpoint predictions, hashes, sample/background
separation, out-of-fold coverage and attribution conservation. The maximum
conservation error was 8.88e-16. A binary-input CPU shortcut for KAN predictions
was validated against saved predictions. The installed Torch build was 2.11.0+cpu,
so the GPU was not used for this extension.

Code changes after
execution must not be silently substituted when reproducing a receipt.
Training-set summaries are descriptive complements to held-out analysis.
No final full-cohort model or new gene/pathway grouping was fitted in this extension.

Recorded mean chromosome-importance rank correlations between training and
held-out summaries ranged from 0.973 to 0.991; top-100 SNP-pair overlaps ranged
from 0.720 to 0.842. Training-set deletion support was descriptive and did not
replace held-out enrichment evaluation or remove prediction gaps.
