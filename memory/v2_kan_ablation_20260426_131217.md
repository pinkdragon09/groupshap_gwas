# Bloom yeast KAN ablation folds and seeds

**Note date:** 2026-04-26 13:12:17

`scripts/history/yeast_bloom_kan_ablation.py` drove each configuration in the KAN
ablation grid. It reused phenotype loading, model construction, training and CV
from `scripts/history/yeast_bloom_kan_train.py`, and pairwise interaction computation
from `scripts/history/yeast_bloom_kan_interaction.py`.

Each configuration used five-fold CV with seed 42, followed by a panel-wide fit
with a 90/10 fitting/early-stopping split. The interaction sweep covered all
panel SNP pairs, with 30 Monte Carlo samples, eight workers and seed 42.
Adam used learning rate 0.001, batch size 64, 200 epochs and patience 25.

The worker seed for pair index `pi` was
`random_state + (pi + 1) * (n_eval + 1) * 1009`, where `n_eval` is the number
of evaluation rows. Explicit settings are retained here so the configuration
does not depend on an external baseline specification.
