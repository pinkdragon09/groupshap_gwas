# FT10 input preflight and Python invocation failure

**Note date:** 2026-04-25 17:46:36

The early FT10 RF workflow checked its phenotype archive, full genotype HDF5,
kinship HDF5 and PC-adjusted GWAS hit table before execution. The checked input
sizes were approximately 1.6 MB, 919 MB, 10 MB and 25 KB, respectively.

An initial invocation using `python` failed because that session's default
interpreter was Python 2. Invoking the runner with `python3` succeeded. The
recorded CPU runtime was 782 seconds. This interpreter observation is historical.

The retained producer is `scripts/history/run_ft10_nonlinear.py`. Its retained
numerical outputs under `outputs/history/ft10/ft10/` include:

- `cv_metrics.tsv`: per-fold prediction metrics.
- `per_snp_shap.tsv`: SNP-level GWAS and SHAP ranks for the 200-SNP panel.
- `gene_window_shapley.tsv`: grouped Shapley values for 86 gene windows.
- `gene_window_cpi.tsv`: gene-window permutation importance.
- `gene_window_manifest.tsv`: SNP-to-group assignments.

The complete raw genotype HDF5 was an input to that run and is not bundled with
this archive. This execution record is not a claim that the relocated historical
runner can be rerun without restoring its required inputs and configuration.
